## 一，外边距margin

### 1.基本使用

- 可以用来设置盒子与盒子之间的间距-外边距

- 语法

  ```css
  margin-top
  margin-bottom
  margin-left
  margin-right
  复合属性：margin
  一个值：上下左右
  两个值：上下  左右
  三个值：上 左右 下
  四个值：上 右  下 左
  
  margin: 200px 20px 5px 50px;
  ```

  

### 2.使用技巧

#### （1）盒子水平居中

`margin:0 auto`:可以设置盒子水平居中，设置上下外边距为0，左右auto，auto代表的是自适应，会自动将父标签的剩余空间均分给盒子两边。（针对有宽度的块级标签有效果）

注意：垂直方向上的auto被禁用，原因在于一般父标签的高度由内容决定，高度无法确定，w3c将垂直方向上的auto禁用了

#### （3）盒子水平垂直居中

- 水平居中：`margin:0 auto`
- 垂直居中：`margin-top:calc((父盒子高度 - 子标签的高度)/2)` 或者`margin-top:calc(50% - 子标签高度的一半)`
  - calc()可以进行数学运算，运算符号前后**添加空格**
  - `margin-top:calc(50% - 子标签高度的一半)`:只适用于父标签宽高一样时

#### （3）margin设置百分比

- margin设置百分比时，无论哪个方向，参考的都是父标签的宽度



注意：可以使用负值

### 3.margin传递性

- 子标签在设置`margin-top`时，会传递给父标签显示

- 原因：在标签在设置`margin-top`时，会去找父标签边界作为参考，找不到父标签的边界，就传递给父标签显示

- 解决方案：

  - 可以给父标签设置边框`border`,会改变盒子的大小

  - 可以给父标签设置内边距`padding`,会改变盒子的大小

  - 可以给父标签设置`overflow:hidden`,借助BFC容器的特点，容器里面的元素不会影响外面元素的布局。【推荐】

    `overflow`:处理标签内容溢出时的显示效果

    - `auto`:内容不溢出就没有影响,溢出的正常显示
    - `hidden`:内容不溢出没有影响，溢出的部分会隐藏

### 4.margin重叠性

- 相邻的两个盒子在垂直方向上的margin会发生重叠，以值大的为准；在水平方向上，margin不会发生重叠，是相加在一起。

## 二，边框

- 可以设置标签四周的边框，主要由：边框的方向，宽度，类型，颜色

- 语法

  ```css
  边框三要素
  border-方位单词-width:宽度
  border-方位单词-style:类型
  border-方位单词-color:颜色
  
  复合属性
  可以设置一条边框的符合属性
  border-方位：宽度 类型  颜色；
  
  同时设置四条边框的符合属性：
  border：宽度 类型  颜色
  ```

- 颜色：

  - 颜色单词
  - `#十六进制`
  - `rgb(0~255,0~255,0~255)`

- 类型：

  - `solid`：单实线
  - `dashed`:虚线
  - `dotted`:点线
  - `double`:双实线

- 注意:

  - 边框至少需要设置两个值：宽度和类型，颜色默认是黑色

  - 默认边框区域会铺设背景颜色

  - 边框会改变盒子的大小

  - 如果只设置一条边框，显示为矩形；如果由相邻的边框，两条边界相接部分是沿着对角线区域均分；可以绘制三角形，设置盒子的宽高为0，三条边框设置为透明色，一条边框不透明

    ```css
    	.box2{
    			width: 0px;
    			height: 0px;
    			/* background-color: pink; */
    			border-top: 50px solid transparent;
    			border-left: 50px solid plum;
    			border-right: 50px solid transparent;
    			border-bottom: 50px solid transparent;
    		}
    ```

    

## 三，内边距padding

- 设置盒子中内容与边距之间的间距

- 语法

  ```css
  padding-top
  padding-left
  padding-bottom
  padding-right
  复合属性padding
  一个值：上下左右
  两个值：上下  左右
  三个值：上  左右  下
  四个值：上 右  下 左	
  ```

- 注意：

  - padding区域默认会铺设背景颜色
  - 内边距padding会改变盒子的大小

## 四，标准盒模型

目前使用div+css布局，在布局过程中，都是由一个个盒子构成的页面

![image-20250220155254742](https://woniumd.oss-cn-hangzhou.aliyuncs.com/web/dingling/20250220155254.png)

任何盒子都由以下几个部分构成

- content：代表内容区域，存放内容的空间，可以是文本或其他标签
- padding:代表内边距，盒子边框和内容之间的间距
- border：代表边框，盒子四周的边框
- margin:代表外边距，盒子与盒子之间的间距

## 五，标准盒子大小的计算

盒子真正的大小：

- 宽度=width(content区域) + padding*2（左右）+border * 2(左右)
- 高度=height(content区域) +padding*2（上下）+border * 2(上下)



盒子在页面中所占空间的大小

- 宽度=width(content区域) + padding*2（左右）+border * 2(左右) + margin *2(左右)
- 高度=height(content区域) +padding*2（上下）+border * 2(上下) + margin*2（上下）
