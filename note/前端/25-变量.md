## 变量

### 一，概念

JS中的变量，可以理解为一个保存数据的容器，或者也可以将变量作为是给每一条数据取的名字

作用：

1. 保存数据
2. 给数据取名字



当数据通过变量保存之后，可以方便我们对数据进行反复使用

### 二，基本语法

#### 1.创建变量

JS提供了3种创建变量的方式，其中一种是ES5的语法，另外两种是ES6的语法

```html
	// ES5
		var name = '张三'
		console.log(name);
		// ES6
		let age = 18;
		const tel = '131222222'
		console.log(age);
		console.log(tel);
```

说明：

1. 以上代码都是在创建变量，并保存数据
2. 上面代码中的`=`，不是数学中的等号，在JS中，叫赋值符
3. ”赋值符“的作用就是将右边的数据赋值给左边的变量

#### 2.3种方式的选择

var能实现的效果，let和const都能实现，并且语法规则更为严谨，因此，三个中，优先ES6的两种，let和const

let和const的区别

1. let保存数据，后续还可以通过`赋值符`修改数据
2. const保存数据，后续不能修改

#### 3.修改变量数据

实际上就是通过`=`来对变量进行重新赋值

```html
<body>
	<script>
		let age = 18;
		const name = "占山"
		age = 22;
		console.log(age);
		name = "wangwu"
		console.log(name);
	</script>
</body>
```

#### 4.注意事项

使用let和const创建变量时

1. 变量名不能重复
2. 变量名由字母，数字，下划线，$美元符号组成，但是不能以数字开头
3. 变量名不能使用JS中的关键字（class，for，let...)

