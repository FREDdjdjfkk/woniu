## 一，css定位

通过`position`属性来设置标签的定位

### 1.静态定位

- 页面中所有的标签默认都是静态定位，元素在标准文档流中

- 语法

  ```css
  position: static;
  ```

### 2.固定定位

- 可以让元素固定在页面上，不会随着滚动条滚动

- 语法

  ```css
  position: fixed;
  ```

- 设置偏移量（移动量）

  - `top`:距离参考位置上边缘的间距
  - `bottom`:距离参考下边缘的间距
  - `left`:距离参考左边缘的间距
  - `right`:距离参考右边缘的间距

- 特点：

  - 固定定位的元素会脱离文档流，让元素固定在页面上，不会随着滚动条滚动
  - 原来空间不再占用
  - 如果只设置固定定位，元素会在当前位置脱离文档流，一旦设置偏移量，元素会参考整个显示区域进行移动

### 3.相对定位

- 语法

  ```css
  position: relative
  ```

- 设置偏移量（移动量）

  - `top`:距离参考位置上边缘的间距
  - `bottom`:距离参考下边缘的间距
  - `left`:距离参考左边缘的间距
  - `right`:距离参考右边缘的间距

- 特点

  - 相对定位的元素不会脱离文档流，会破坏文档流进行移动，显示在标准文档流之后
  - 原来的空间还占用
  - 如果只设置相对定位，对元素本身没有任何影响，一旦设置了偏移量，元素会参考盒子原来的位置进行移动

- 注意：

  - 父元素移动时，子元素会跟着移动

  - 相对定位一般很少单独使用，会配合绝对定位一起使用

### 4.绝对定位

- 语法

  ```css
  position: absolute;
  ```

- 设置偏移量（移动量）

  - `top`:距离参考位置上边缘的间距
  - `bottom`:距离参考下边缘的间距
  - `left`:距离参考左边缘的间距
  - `right`:距离参考右边缘的间距

- 特点：

  - 绝对定位的元素会脱离文档流，显示在标准文档流之上
  - 原来的空间不再占用
  - 如果只设置绝对定位，元素会在当前的位置脱离文档流，一旦设置了偏移量，绝对定位的元素默认是参考整个显示区域进行移动或参考最近的**定位父级**进行移动

  

  **子绝父相**

  ##### （1）结构父级

  - 指的是html结构中的父标签

  ##### （2）定位父级

  - 绝对定位的元素可以参考某个父级标签作为参考进行移动，这个父级标签就是定位父级，定位父级需要手动设置
  - 注意：
    - 相对定位，绝对定位，固定定位（除了静态定位）的元素都可以作为绝对定位的元素的定位父级
    - 如果设置了多个定位父级，绝对定位的元素会参考最近的定位父级进行移动
    - 一般常用相对定位作为定位父级，只设置相对定位，对元素本身，没有任何影响
    - 如果作为定位父级的标签上本身就有定位时，也可以作为里面子元素的定位父级
    - 绝对定位的元素宽度设置百分比时，是参考定位父级的宽度

  

##     二，文档流的概念

标准文档流：在页面布局过程中，元素默认按照从上到下，从左到右，块级元素独占一行，行级元素共享一行的排列规范来进行排列

脱离文档流：在页面布局过程中，元素不再遵循标准文档流的规范，按照自己的排列规范来进行排列

破坏文档流：在页面布局过程中，元素在移动过程中不遵循标准文档流的规范，在移动完成后仍然在标准文档流中

## 三，定位层级

- 设置定位元素的显示顺序

- 当给元素设置定位（静态定位除外）时，后面定位的元素会盖住前面定位的元素

- 语法：

  ```css
  	z-index: 数字;
  ```

  - 默认值相当于0，数字越大，代表设置的定位层级越高，显示在上方，数字相同时，后面定位的元素会盖住前面定位的元素

- 注意：

  - `z-index`只针对相对定位，绝对定位，固定定位的元素有效（静态定位没有效果）

## 盒子居中技巧

`margin：auto auto`：可以让元素水平居中，无法垂直居中，原因在于垂直方向上的高度一般是由内容撑开，无法确认，所以禁用

### 1.通过margin和定位实现水平垂直居中

1. 设置大盒子为定位父级

2. 小盒子：设置绝对定位

   ```css
   margin: auto auto;
   /* 设置绝对定位 */
   position: absolute;
   /* 规定居中的范围 */
   top: 0;
   left: 0;
   right: 0;
   bottom: 0;
   ```

   

   ```html
   <head>
   	<style>
   		body {
   			margin: 0;
   		}
   
   		.box {
   			width: 100%;
   			height: 100vh;
   			background-color: rgba(0, 0, 0, .3);
   			position: fixed;
   			top: 0;
   		}
   
   		.item {
   			width: 600px;
   			height: 600px;
   			background-color: orange;
   			margin: auto auto;
   			/* 设置绝对定位 */
   			position: absolute;
   			/* 规定居中的范围 */
   			top: 0;
   			left: 0;
   			right: 0;
   			bottom: 0;
   
   		}
   	</style>
   </head>
   
   <body>
   	<div class="box">
   		<div class="item"></div>
   	</div>
   </body>
   ```
