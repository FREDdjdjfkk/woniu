# 内部类

```properties
类里面的类
```

## 静态内部类

```properties
想象成静态变量
```

静态内部类声明:

```java
public class Outer {

//    访问修饰符  static 数据类型 变量名
    public static class Inner{
        //里面可以写之前外部内种所有的东西

        public void testInner(){
            System.out.println("inner test方法");
        }

    }

    public void testOutter(){
        System.out.println("outter test");
    }


}
```

```java
   Outer.Inner inner = new Outer.Inner();
   inner.testInner();
```





## 成员内部类

```properties
看成类的成员变量
```

```java
public class Outer {

//    成员变量:访问修饰符   数据类型 变量名
    public  class Inner{
        //里面可以写之前外部内种所有的东西
        public void testInner(){
            System.out.println("inner test方法");
        }

    }

    public void testOutter(){
        System.out.println("outter test");
    }


}
```

创建成员内部类对象(了解)

```java
Outer.Inner inner = new Outer().new Inner();
```



## 局部内部类

```properties
想象成局部变量,在方法中声明,只能在方法中使用当前内部类
```

```java
 public void testOutter(){
        System.out.println("outter test");

        //局部内部类
        class InnerMethod{
            public void testInnerMethod(){
                System.out.println("InnerMethod");
            }
        }


        InnerMethod innerMethod = new InnerMethod();
        innerMethod.testInnerMethod();

    }

```



## 匿名内部类

```properties
类似局部内部类,也只能在方法中使用
```

```java
        USB usb = new USB() {//  new USBImpl  implements USB
            @Override
            public void chongdian() {
                System.out.println("匿名内部类充电");
            }
        };

        usb.chongdian();
```

相当于new了一个实现了某个接口的实现类对象（只是这个实现类没有名字）

```java
       JButton button = new JButton("登录");

        JButton button1 = new JButton("注册");
```

## Lambda表达式

### 是什么

```properties
函数式接口
JDK1.8的新特性，允许把一个函数作为参数
```

```java
//        USB usb = new USB() {  
//            @Override
//            public void chongdian() {
//                System.out.println("方法的实现");
//            }
//        };

        USB usb = ()-> {
            System.out.println("方法的实现");
            System.out.println("xxxx");
        };

        usb.chongdian();
```



```properties
简化匿名内部类的编写

前提：接口中有且只有一个抽象方法
```

```java
@FunctionalInterface
public interface IA {

    void b();
}
```

@FunctionalInterface

用来标准当前接口是一个函数式接口,可以使用lambda表达式创建匿名对象

### 语法

```properties
= (参数列表)->{方法体;};
```

参数列表

```properties
无参
() ->  ......;

一个参数
(x) -> ....;
或者
x ->.....;

多个参数
(x,y)->.....;
```

方法体

```properties
{方法体;};

有且只有一条执行语句时，可以省略{}，有多条不能省

```

返回值:

```properties
{
方法体最后一行return xxx;
}

如果方法体有且只有一行return语句时  {}可以省，return也可以省
```
