## 编写一个类 

比如:手机类

属性:

​	品牌  颜色  价格  大小 ....

行为:

​	打电话 上网 发短信 ....



```java

public class Phone {

    //属性 (成员变量)
//    品牌  颜色  价格  大小 ....
    String brand;//品牌

    String color;//颜色

    int price;//价格

    double size;//大小

    //行为 (成员方法)
    public void call(){
        System.out.println("打电话");
    }

    public void internet(){
        System.out.println("上网");
    }

    public void sendMsg(){
        System.out.println("发短信");
    }
}

```

## 包package

```properties
包实则对应的磁盘中文件夹

包在程序中是用来管理类的
```

```
package service;  //表示当前类所在的包的位置
```

注意：

- 在同一个包中使用其他类不需要导包，直接用

- 在不同的包中使用其他包中的类，需要导入包  import 包名

  ```java
  import entiry.User;  //导入制定类
  
  import entiry.*;  //导入包中所有类
  ```

- java.lang包下的类可以直接使用(不需要导包)

## 访问修饰符

| 访问修饰符 | 说明                                   |
| ---------- | -------------------------------------- |
| public     | 公共的,在程序的中任意地方可以访问      |
| protected  | 受保护的 可以在当前包中,不同包的子类中 |
| 默认的     | 默认的  只能在当前包中                 |
| private    | 私有的  只能在当前类中                 |



### public

```properties
 修饰类  
     一个源文件里面只能有一个public的类，并且此public的类要和源文件名字一致
     public 默认的可以修饰源文件的类(抛开内部类)
 修饰成员变量，方法
```

### protected

```properties
 修饰成员变量，方法
 受保护的 可以在当前包中,不同包的子类中 (和继承相关)
```

### 默认的(不写)

```properties
 类,修饰成员变量，方法
 受保护的 可以在当前包中,不同包的子类中 (和继承相关)
```

### private

```properties
 私有的
 成员变量，方法
 只能在当前类中使用
```
