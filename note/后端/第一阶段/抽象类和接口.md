# 抽象类

```properties
当父类中的方法没有实现意义的时候，但又希望每个子类都要有这个方法，这个时候可以将父类中的这个方法设置为：抽象方法
```

## 抽象方法

```properties
没有方法体
public abstract void attack(Zombies zombies);
```

用abstract修饰的方法就是抽象方法



有抽象方法的类，必须为抽象类

## 抽象类

```properties
用abstract修饰的类就是抽象类
```

注意:

- 有抽象方法的类必须为抽象类
- 抽象类不一定有抽象方法
- 一个抽象类的设计用来被继承的

## 继承抽象类

```properties
如果子类继承一个抽象类，需要重写里面的抽象方法

可以全部重写，可以部分重写

如果没有全部重写，当前子类必须为抽象类

最底层的子类，一定是实现了上层类的所有抽象方法
```

```java

public abstract class A {

    int a = 10;

    public A(){
        System.out.println("构造方法");
    }

    public  abstract int sum(int a,int b);

    public abstract void test();
}

class B extends A{

    @Override
    public int sum(int a, int b) {
        return 0;
    }

    @Override
    public void test() {
        
    }
}

```

## 抽象类的特征

```pro
1,可以没有抽象方法
2，有抽象方法的类必须是抽象类
3,抽象类不能被实例化
```

重点：抽象类不能被实例化，只能new抽象类的子类（使用父类引用指向子类实例）

```java
public abstract class A {

    int a = 10;

    public A(){
        System.out.println("构造方法");
    }

    public  abstract int sum(int a,int b);

    public abstract void test();
}

abstract  class  B extends A{

    public B(){
        System.out.println("B的构造方法");
    }
    @Override
    public int sum(int a, int b) {
        return 0;
    }

}

class C extends B{

    @Override
    public void test() {

    }
}

class Test{
    public static void main(String[] args) {

        B b = new C();
    }
}
```

# 接口

```properties
简单来说：就是比抽象类还要抽象的类

全部是抽象方法(jdk1.8开始，支持静态方法和默认default方法,jdk1.9开始支持私有方法,实际开发中，不会用)
```

## 接口的声明

interface关键字声明接口

```java
public interface USB {
    
}
```

接口是一种约定

```java
接口中的方法:默认是public abstract
    
接口中的变量:默认是public static final的  公共的静态常量
```

## 接口的实现

一个类实现接口:implements

```java

public interface IA {

    void test1();

    void test2(String str);
}

  class CA implements IA{

     @Override
     public void test1() {

     }

     @Override
     public void test2(String str) {

     }
 }

```

注意:一个类去实现某个接口，需要实现里面的所有抽象方法，否则这个类就是抽象类

## 接口的多实现

```properties
类  implements 接口1,接口2...{

}
```



```java

public interface IA {

    void test1();

}

interface IB {

    void test2();

}

interface IC {

    void test3();

}



class CA implements IB,IC{


    @Override
    public void test2() {

    }

    @Override
    public void test3() {

    }
}

```

## 一个类继承某个类再实现接口

```java
interface I1{

}

interface I2{

}

class C1{

}

class C2 extends C1 implements I1,I2{

}
```



类与类的关系:  继承

类与接口的关系: 实现

接口与接口的关系: 继承

## 接口的继承

```java
interface I3 extends I1,I2{

    void test3();

}
```

支持多继承
