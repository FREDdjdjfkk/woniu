# 枚举

## 是什么

```properties
是一种特殊的数据类型,这种数据类型限制的值的取值范围

枚举是一组常量的集合。枚举类属于一种特殊的类，里面只包含一组有限的特定的对象
```

## 为什么要用枚举类型

```properties
把一些有限的固定的数据放入枚举中，可以控制值的范围
```

## 声明枚举

```properties
public enum WeekDay{
	
} 
```
