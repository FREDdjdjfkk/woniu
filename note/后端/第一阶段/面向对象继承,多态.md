## 方法的重写

```properties
重载:  方法名相同，参数列表不同  和返回值，访问修饰符无关

重写:  子类对父类方法的重写
	  访问修饰符（一致，扩大）  返回值类型（一致，缩小(可以是子类)） 方法名（和父类方法名一致） 参数列表（一致）{
	  
	  }
```

访问修饰符:  要么一致，要么可以扩大范围

返回值类型: 保持一致或者缩小为父类方法返回值类型的子类

方法名：必须一致

参数列表：必须一致

## @Override

```properties
当你方法的要求达到重写的条件，有没有Override都是一样的

如果方法上有Override,那么方法必须满足重写的条件

```



## 什么方法不能被重写

```pro
1,私有的方法不能被重写（不能被继承）
2,用final所修饰的方法不能被重写
```

## final

可以修饰类，变量，方法

- final所修饰的类不能被继承
- final所修饰的变量是常量，不能被修改
- final所修饰的方法不能被重写



# 多态

```properties
多态是同一个行为具有不同的表现形式或形态的能力
```

## 实现多态方式两种

- 重载式多态（静态多态）

    方法的重载   (发生在编译阶段，运行之前)

- 重写式多态 (动态多态)

  ​	方法的重写 （继承） 发生在运行阶段

  表现形式:

  - 通过类型表现

    ```java
      //使用父类类型引用指向子类的实例
            Animal animal = new Cat();
            
            animal.jiao();
    ```

    

  - 通过参数表现

    如果参数是父类类型，可以传子类对象

    ```java
      public void lingYang(Animal animal){
    
            animal.jiao();
        }
    ```

    

  - 通过返回值类型表现

     如果返回值是父类类型，可以返回子类对象

      ```java
      public Animal yang(){
     //        Animal a = new Animal();
     
          Dog dog = new Dog();
     
          Cat cat = new Cat();
     
          return cat;
      }
      ```

  

  ## 引用数据类型转换

  ### 向上转型

  自动转换

  ```properties
  子类类型转换为父类类型
  
  Animal animal = new Dog();  
     子类特有的属性和方法会丢失
     如果子类重写了父类的方法，则调用是子类重写后的方法
  ```
  
  ### 向下转型

  强制转换，类型还原

  ```properties
  把父类类型转为子类类型
  ```
  
  ```java
  //父类引用指向子类的实例
          Animal dog = new Dog();
  
          dog.jiao();
  
  
          //还原类型  向下转型  把父类类型转为子类类型
          Dog newDog = (Dog) dog;
  ```
  
  

  注意：你new的是什么，才能还原成什么

  否则会抛出类型转换异常   ClassCastException

  ## instanceOf

  ```properties
  用于判断一个对象是否属于某种数据类型
  ```
  
  ```java
   public void lingYang(Animal animal){
  ```
