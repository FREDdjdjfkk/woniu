约束：

- 主键约束 

  Primary key 

  ```properties
  通常每个表都要求有个主键，目的是为了提高对数据操作的效率
  
  表中的第一个字段会设置为 主键列 
  
  主键特征：不能为空，唯一不可重复
  
  userId int PRIMARY key auto_increment,
  
  auto_increment自动增长  默认增量
  
  具备主键索引
  ```

- 外键约束

   ```properties
  用于表示表与表之间的关联关系
  ```

  关联关系:

  一对一:   一个用户对应一个身份证  一个丈夫对应一个妻子

  ![image-20250317142954556](https://woniumd.oss-cn-hangzhou.aliyuncs.com/java/renxiaohua20250317142954.png)

  ```mysql
  create table userInfo(
  	user_id int PRIMARY key auto_increment,
  	user_name VARCHAR(20),
  	user_phone VARCHAR(11)
  )
  
  create table idcard(
  	card_id int PRIMARY key auto_increment,
  	card_no VARCHAR(20),
  	intervalDate date,
  	user_id int UNIQUE,
  	FOREIGN KEY(user_id) REFERENCES userInfo(user_id)
  )
  ```

  一对多:

  ![image-20250317143724843](https://woniumd.oss-cn-hangzhou.aliyuncs.com/java/renxiaohua20250317143724.png)

  多对多:

  ![image-20250317144514161](https://woniumd.oss-cn-hangzhou.aliyuncs.com/java/renxiaohua20250317144514.png)

  ```properties
  优点：保证数据的完整性和一致性(完全可以使用程序逻辑代替)
  缺点:  每一次对数据做增删改操作时,外键约束都会生效
  ```

  实际开发中，有外键列，没有外键约束

  

- 非空约束

  ```properties
  not null  不允许为空
  ```

- 唯一约束

  ```mysql
  UNIQUE  不允许重复
  ```

- 默认约束

  default

  ```mysql
  create table userInfo(
  	userId int PRIMARY key auto_increment,
  	username varchar(20) not null,
  	usersex char(1) default '男',
  	birthday date
  )
  ```

  

- 检查约束(8.0之后生效)

  ```mysql
  userAge int check(userAge>0 and userAge < 100)
  ```

  数据库表设计时遵循的三大范式：

  第一范式: 1NF

  ```properties
  列具备原子性
  通俗：列不可再分
  ```

  ![image-20250317151915734](https://woniumd.oss-cn-hangzhou.aliyuncs.com/java/renxiaohua20250317151915.png)

  第二范式:

  ```properties
  每一列的值都应该和主键相关
  通俗：每个表只存和表相关的数据
  ```

  第三范式:

  ```properties
  每一列的值都应该和主键直接相关（不能间接相关）,解除传递依赖
  ```

  设计上不完全依赖三大范式，一切还是看需求

添加数据:

```mysql
-- 添加数据
-- insert into 表名（字段名,字段名...） values (值1，值2)

-- 表名(字段名：如果省略，代表所有)

insert into company(id,name,location,builddate)
values(null,'皮包公司1','成都市高新区孵化园','2025-10-01')
-- 哪些字段可以省略  id自动增长,有默认值的,允许为null的字段
insert into company values(default,'皮包公司4','xxx',now())

-- 添加多条记录
insert into company values
(default,'皮包公司4','xxx',now()),
(default,'皮包公司5','xxx',now())
```

删除数据:

```properties
delete from 表名 

delete from company where  条件
```

修改数据:

```properties
update 表名 set 字段名=新的值,字段名2=新的值2 where 条件
```

```mysql

update employee set salary = salary + 500
```

### DQL

```properties
Data Query Language
数据查询语言
主要对数据做查询操作
select
```

```mysql
-- select 'a'

-- 投影 
select id,buildDate from company

select 字段名,字段名2....  from 表名

select * from 表名  * 表示所有字段，实际开发中不要使用*


-- 别名 as  as可以省略
select id companyId,name companyName,location as 地址,buildDate as 创建时间 FROM company


-- 条件 where
-- 比较运算符 = !=(<>) > < >= <=
-- 逻辑运算符 and or not(一般不用)
-- 空值运算符 is null 或者 is not null
-- 范围运算 BETWEEN and  闭区间
-- in 范围  in(范围) 或者not in
-- like 模糊查询 通配符_(匹配任意一个字符)  
-- %匹配0个或多个字符
select * from company where buildDate > '2010-01-01'

select * from employee where  location is not null

select * from employee where salary BETWEEN 10000 and 20000

SELECT * from company where id not in (1,2,3)


select * from employee where name like '%君%'

-- 能够在select中用到的所有where条件都能在update和delete语句中使用

-- 排序
order by 字段  asc(默认升序)  desc(降序)
order by 字段1,字段2  字段1相同的情况下再按照字段2排序

select * from employee ORDER BY salary desc,
joinDate desc 

-- 聚合函数
-- count(*) sum() max() min() avg()
select count(0) from employee

select max(joinDate) FROM employee where deptId = 1

-- 分组
-- 分组的目的是为了做聚合处理
SELECT ismale,count(*) from employee GROUP BY ismale
select 后面只能跟分组后的字段或者聚合函数

select deptId,ismale,count(*) from employee GROUP BY deptId,ismale

group by 字段1，字段2... by后面的字段数据相同为一组，每一组有多条记录，只能做聚合处理

对分组后的结果做筛选用having   having后面跟的条件只能是分组的字段或者聚合函数

select deptId,count(*) from employee where salary > 10000
 group by deptId having count(*) > 30
 
 where是对group by之前的数据筛选，having是对group by之后的结果筛选
 
 -- 限制查询 limit
 -- limit beginIndex,size
 -- limit (currentPage-1)*pageSize,pageSize
 select * from employee limit 20,10
 
 select * from employee order by salary desc
  limit 3
  
  -- DISTINCT(字段) 对某个字段去重处理 了解
select DISTINCT(location) from employee

-- UNION 拼接结果集
-- 默认是去重拼接
select 'a'
UNION all 
select 'a'
```



sql的书写顺序:

select , from , where,group by having order by limit
