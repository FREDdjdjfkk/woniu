## 常用的HTML标签

### 1.div标签

- 可以看作是一个布局容器，里面可以嵌套其他标签，没有任何样式，`默认独占一行`。后续网页中常用div标签来进行布局

- 语法

  ```html
   <div>我是div</div>
  ```

### 2.标题标签

- 表示网页中的标题

- 语法

  ```html
      <h1>h1</h1>
       <h2>h2</h2>
       <h3>h3</h3>
       <h4>h4</h4>
       <h5>h5</h5>
       <h6>h6</h6>
  ```

- 注意：

  - 默认会加粗，数字越大，字体越小
  - 默认标签上下有外边距margin
  - 默认独占一行
  - 优点：有利于搜索引擎收录，利于SEO优化

### 3.段落标签

- 一个段落就是一个p标签，排列不下，自动换行显示

- 语法：

  ```html
    <p>p标签</p>
  ```

- 注意

  - 默认独占一行
  - 默认上下都有外边距margin

### 4.span标签

- 用于包裹简短文本或者提示信息，可以同行显示

- 语法

  ```html
   <span>span标签</span>
  ```
