## 运算符

### 一，数学运算符

| 运算符 | 说明                                                | 示例                                                  |
| ------ | --------------------------------------------------- | ----------------------------------------------------- |
| +      | 1.作为数学符号进行数字求和 <br>2.字符串之间的拼接符 | 10+2,结果为12 <br>'hello' + 'word' ,结果为’hello word |
| -      | 数学符号种的减号                                    | 100-20,结果为80                                       |
| *      | 数学种乘号                                          | 2*3，结果为6                                          |
| /      | 数学种除号                                          | 100/5，结果为20                                       |
| %      | 计算两个数之间的余数                                |                                                       |
|        |                                                     |                                                       |
|        |                                                     |                                                       |

```js
const a = '4';
const b = 7;
let c = a + b; //结果 '47'
let d = b - a  //3
let e = a * b  //28
let f = b / a
let g = b % a // 3
console.log(g);
```
