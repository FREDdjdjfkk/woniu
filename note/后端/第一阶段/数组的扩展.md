练习:

1, 声明一个字符串类型的二维数组,用于存放用户信息,要求打印出每一个用户的详细信息

```java
  String[] user1 = {"admin","12345","18","510xxxx"};
        String[] user2 = {"oliga","45678","18","510xxxx"};
        String[] user3 = {"test","12345","20","510xxxx"};

        String[][] users = {user1,user2,user3};

        //foreach
        for(String[] user:users){
            //拿到每一个一维数组
            for(String info:user){
                System.out.print(info+" ");
            }
            System.out.println();
        }

        //普通for 遍历二维数组
        for(int i = 0;i<users.length;i++){
            //拿到每一个一维数组
            String[] user = users[i];

            //遍历一维数组
            for(int j = 0;j<user.length;j++){
                System.out.print(user[j]+" ");
            }
            System.out.println();

        }

        //普通for 遍历二维数组
        for(int i = 0;i<users.length;i++){
            //遍历一维数组
            for(int j = 0;j<users[i].length;j++){
                System.out.print(users[i][j]+" ");
            }
            System.out.println();

        }
```



2，新建一个数组，将之前数组中的数据复制到新数组中  （可以用一维数组，也可以用二维数组）

```java
        //新建一个数组

        int[] nums = {1,2,3,4,5};

        //新数组  长度和旧数组一致
        int[] newNums = new int[nums.length];

        for(int i = 0;i<nums.length;i++){
            //获取旧数组中每一个元素
            newNums[i] = nums[i];
        }

        for(int num:newNums){
            System.out.print(num+" ");
        }
```

## 数组扩容

![image-20250303142427001](https://woniumd.oss-cn-hangzhou.aliyuncs.com/web/dingling/20250303142427.png)

```java
 //数组的扩容
        int[] oldNums = {1,2,3};

        int number = 4;

        //创建一个新数组，长度为老数组+1
        int[] newNums = new int[oldNums.length+1];

        //将老数组中的数组拷贝到新数组中
        for(int i = 0;i<oldNums.length;i++){
            newNums[i] = oldNums[i];
        }

        newNums[newNums.length-1] =number;

        System.out.println();

```

## 数组的拷贝

```properties

数据类型[]  新数组 = Arrays.copyOf(老数组,扩容后新数组的长度);

Arrays.copyOf执行后会产生一个新数组


 System.arraycopy(老数组,老数组中需要被拷贝元素的起始索引,新数组,数据存放在新数组的索引位置,拷贝的长度);
 
Arrays.copyOf的底层实际上就是System.arraycopy
```

```java
       int[] oldNums = {1,2,3,4,5,6,7};

        int[] newNums =  Arrays.copyOf(oldNums,2);

        System.arraycopy(oldNums,2,newNums,0,4);

        System.out.println();
```
