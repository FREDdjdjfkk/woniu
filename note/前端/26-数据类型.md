## 数据类型

### 一，数据类型的概念

在我们开发中，我们会遇到许多数据，这些数据可以分成不同的类型，例如中文数据属于字符串，数字数据就属于数字类型

### 二，数据类型的分类

两大类

- 基本类型
- 引用类型

#### 1.基本类型

基本类型中，包含了7种数据类型（前5个是ES5的）

- string：字符串
- number:数字
- boolean:布尔值
- undefined：未定义
- null:空
- symbol:唯一值（ES6）
- bigint：无穷大（ES10)

##### （1）字符串

只要数据用引号包裹起来，那么这条数据就是字符串，引号有3种选择

```js
let name="王五";
let user='李四';
let tel=`131222222`
```

##### (2）数字

```js
let a =1;
let b=0.2;
let c=.2
let d =-10
```

JS中还有一种特殊的数据 NaN,也属于数字类型

说明：

- 实际开发中，我们不会主动去使用NaN,大部分时候是因为我们做了不合法的数学运算，会得到一个NaN的结果；
- NaN和任何数据都不相等，包括他自己

##### （3）布尔值

只有两条数据：true和false，分别代表真和假

```js
let a =true; //代表真
let b=false; //代表假
```

##### （4）未定义

在数据类型中，只有一条数据：undefined

实际开发中，我们不会主动给一个变量赋值undefined，通常是因为我们创建了变量，但是我们没有给变量赋值，从而得到变量的类型是undefined

```js
		let e;
		console.log(e);//undefined
```

##### （5）空

在空类型中，只有一条数据:null

实际开发中，我们不会主动给一个变量赋值null
