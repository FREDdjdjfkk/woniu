## 选择器

- 用于找到页面中标签来作用css代码

#### （1）基础选择器

##### 1.标签选择器

- 通过标签名找到满足条件的标签作用css代码

- 语法

  ```css
  	标签名{
  			css属性名1: css属性值1；
                css属性名2: css属性值2;
  		}
  ```

##### 2.类选择器（class选择器）

- 通过标签上class属性属性值找到满足条件的标签

- 语法

  ```css
  .class名{
  			css属性名1: css属性值1；
                css属性名2: css属性值2;
  		}
  ```

##### 3.id选择器

- 通过标签上的id名找到满足条件的标签

- 标签上id名是唯一的，同一个网页同名的id只能有一个，只能找到唯一的一个标签

- 语法

  ```css
  #id名{
  			css属性名1: css属性值1；
                css属性名2: css属性值2;
  		}
  ```

##### 4.通配符选择器

- 找到页面中所有的标签来作用css样式

- 语法

  ```css
  	*{
  			color: red;
  		}
  ```

  作用：去掉标签的浏览器默认样式。如p标签的margin

##### 5.伪类选择器

| 伪类选择器 | 说明                       |
| ---------- | -------------------------- |
| `:link`    | 向未访问过的超链接添加样式 |
| `:visited` | 向访问过的超链接添加样式   |
| `:hover`   | 鼠标移入时的样式           |
| `:active`  | 鼠标按下时的样式           |



##### 6.选择器优先级

##### id选择器>类选择器（class选择器）>标签选择器 >通配符>继承的yan

class可以关联多个样式，HTML从上往下执行，定义在后面的class优先级更高

即相同的选择器，后面的覆盖前面的

#### （2）复合选择器

##### 1.后代选择器（派生选择器）

- 找到指定标签里面所有满足条件的后代标签，可以找到儿子，孙子，重孙子....

- 中间使用`空格`隔开

- 语法

  ```css
  //	找到div标签里面所有class为p1的标签
  div  .p1{
  			color: red;
  		}
  ```

##### 2.交集选择器

- 交集选择器由两个或者多个选择器直接连接组成

- 选择器之间**没有**分隔符（空格，逗号）

- 选取同时满足所有选择器条件的元素

- 语法

  ```css
  //选择所有class即为p1又为span1的标签
  .p1.span1{
  			background-color: orange;
  		}
  ```

##### 3.并集选择器

- 用于同时选择多个不同元素并为他们应用相同的样式规则

- 并集选择器由多个选择器通过逗号`,`分隔组合而成

- 语法

  ```css
  //同时选择class为p1,span1,id为box1 下面的a标签作用样式
  .p1,.span1,#box1 a{
  			color: aqua;
  		}
  ```
