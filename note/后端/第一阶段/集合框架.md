# 集合框架

数组:

```properties
特征:
1,数组的长度是固定的（不可自动伸缩）
2，数组中每一个元素的数据类型是相同的（兼容的）
3,数组中可以有基本数据类型
```

集合：

```properties
一组元素的集合
特征：
1，集合的长度可以自由扩展
2，集合中可以是任意类型的数据（但为了后期更好的维护，建议使用泛型）
3,集合中的元素是引用数据类型
```

## Collection接口

```properties
常用方法:
  
  add(E e) 添加元素
  size()  获取集合的长度
  clear() 删除所有元素 (用得较少)
  contains(E e) 判断集合中是否包含某个元素 (内部使用equals进行比较)
  remove(E e) 删除equals比较相等的元素
  iterator();   // Iterator<String> it = strings.iterator();
```

### Vector(了解)

```properties
数据结构：数组

扩容机制：默认是2倍扩容,如果设置了增量，按照增量扩容
   int newCapacity = oldCapacity + ((capacityIncrement > 0) ?
                                         capacityIncrement : oldCapacity);

特征：查询效率比较高,对删除和增加的效率较低

对外提供的方法加了synchronized,表示是线程安全的
```



### LinkedList

```properties
数据结构：双向链表

特征: 查找效率低,但是添加和删除的效率高于数组，尤其是对首尾操作
```

ArrayList,Vector和LinkedList有什么区别

```properties
ArrayList:数据结构是数组，1.5倍的扩容机制,查找效率高，增删效率低,线程不安全的
Vector:数据结构是数组，默认2倍的扩容机制,查找效率高，增删效率低,线程安全的
LinkedList:数据结构是双向链表，查找效率低，增删效率高，尤其是对首尾操作
```

## Set接口

```properties
无序，不可重复
```

```java
   //无序  存放顺序
        Set<String> stes = new HashSet<>();
        stes.add("test1");
        stes.add("test2");
        stes.add("test3");
        stes.add("test3");//不可重复  数据重复则不会添加

        System.out.println(stes.size());

        for(String str:stes){
            //获取出来的数据是无序的，和存放顺序不一致
            System.out.println(str);
        }
        //因为无序，所以无法像List一样使用下标操作元素
```
