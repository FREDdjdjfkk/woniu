# 文件

## File类

```properties
文件和目录路径名的抽象表示

File对象提供了一些列对文件和文件夹操作的方法
```

常用方法：

```properties
exists() 判断文件或者文件夹是否存在() 

isDirectory() 判断是否为一个文件夹(目录)  

mkdir()新建文件夹

mkdirs() 可以按照路径一层一层的创建文件夹

createNewFile();//新建文件  路径要存在否则会抛异常 

list()  String[]获取当前文件夹下所有文件夹和文件的名字

listFiles()   File[]  获取指定路径下所有的file对象

getName() 获取文件名

delete()  删除空文件夹或者文件
```

## 递归

```properties
在方法中自己调用自己  (前提是一定要结束方法)
```

```java
 public static void main(String[] args) {

        File file = new File("d:\\test");

        readFiles(file);

    }

    public static void readFiles(File file){

        File[] files = file.listFiles();

        for(File f:files){

            if(f.isDirectory()){

                readFiles(f);
            }
            System.out.println(f.getName());
        }
    }
```

## 练习:

### 斐波那契数列

斐波那契数列是这样一组数：1、1、2、3、5、8、13、21...，从第三项开始，每一项都是前两项的和。

- ‌**递归方式**‌：定义一个函数fib(n)，如果n等于1或2，则返回1；否则返回fib(n-1)与fib(n-2)的和。
- ‌**优化递归**‌：由于上述递归方式在计算过程中存在大量的重复计算，可以通过使用记忆化搜索或动态规划来优化。此外，也可以采用尾递归的方式，通过引入两个参数来记录前两项的值，从而避免重复计算。
