## 表格标签

### 1.表格标签

- 在页面中绘制表格
- 语法
  - `<table>`:代表的就是一个表格，一个table就是一个表格,可以设置宽度和高度
  - `<tr>`:代表行，一个tr就是一行,可以设置高度，但是不可以设置宽度
  - `<td>`:代表列，单元格，一个td就是一列,可以设置高度和宽度，但是宽度会影响整列的宽度，高度会影响整行的高度
  - `<thead>`:代表表格表头
  - `<tbody>`:代表表格的内容区域
  - `<tfoot>`:代表表格的尾部

```html
<!DOCTYPE html>
<html lang="en">

<head>
	<meta charset="UTF-8">
	<meta name="viewport" content="width=device-width, initial-scale=1.0">
	<title>Document</title>
</head>

<body>
	<!-- 
	table:代表的就是一个表格，一个table就是一个表格
	border：设置表格边框
	width:设置表格的宽度
	height：设置表格的高度
	align:控制表格的对齐方式 left:默认值，左对齐   center：居中  right：右对齐
	bgcolor:设置表格背景颜色  可以是颜色单词，也可以是16进制 #
	cellspacing:设置单元格之间的间距
	cellpadding：设置单元格中内容与边框的间距


	tr：代表行，一个tr就是一行
	height:设置整行的高度
	align:控制整行单元格内容的对齐方式
	bgcolor:设置整行的背景颜色


	td:代表列，单元格，一个td就是一列
	width:设置单元格的宽度，会影响整列的宽度
	height:设置单元格的高度，会影响整行的高度

	th:代表表头，默认内容水平居中并加粗

	在设置bgcolor  td>tr>table
	-->
	<!-- cellspacing="10px" cellpadding="20px"  -->
	<table border="1" width="" height="" align="center" bgcolor="#ccc">
		<thead>
			<tr height="50px" align="center" bgcolor="pink">
				<th width="50px">姓名</th>
				<td bgcolor="purple">年龄</td>
				<td>性别</td>
			</tr>
		</thead>
		<tbody>
			<tr>
				<td height="100px">张三</td>
				<td>18</td>
				<td>男</td>
			</tr>
		</tbody>

		<tfoot>
			<tr>
				<td>foot</td>
				<td>foot</td>
				<td>foot</td>
			</tr>
		</tfoot>
	</table>
</body>

</html>
```

### 2.表格标签上的属性

- `cellspacing`:设置单元格之间的间距(css:border-spacing)
- `cellpadding`:设置单元格中内容与边框的间距(css:padding)

## 单元格合并

- `rowspan`:合并行，垂直方向上合并单元格
- `colspan`:合并列，水平方向上合并单元格
- 注意：是设置在单元格（td/th)上，不管是跨行还是跨列合并，合并了几个单元格，对应的属性值就写数字几
