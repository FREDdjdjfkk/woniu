## 数据类型转换

### 一，转换方式

JS中，允许对数据类型进行转换，转换的方式有两大类

1. 强制转换（显示转换）：手动通过转换方法对数据进行转换
2. 自动转换（隐式转换）：在进行一些数据操作时，因为数据类型不匹配，JS内部帮我们对数据进行转换



### 二，强制转换

#### 1.转换为字符串

JS中转为字符串的方式有2种

- `String()`:可以将任意类型的数据转为字符串类型
- `toString()`:不能转undefined和null

```js
	let a =22
	let b =String(a)
	let c =a.toString()
	console.log(a);
	console.log(b);
	console.log(c);
```

说明：以上两种方式，都不会改变原来的数据，而是得到一个转换后的新数据

#### 2.转换为数字

JS种转换为数字的方式有3种

- `Number()`:可以将任意类型的数据都转为数字类型
- `parseInt()`:可以将任意类型都转换为**整数**类型
- `parseFloat()`:可以将任意类型的数据都转为浮点数（小数）类型

```js
let num ="123.23a"
let e =Number(num)
let f =parseInt(num)
let m =parseFloat(num)
console.log(num,'num');
console.log(e,'e');
console.log(f,'f');
console.log(m,'m');
```

说明：

- `Number()`:是对数据进行整体判断，如果数据整体不能转为一个合法的数字，则直接得到NaN;
- `parseInt()`:将数据转成整数，他会对数据从左到右一个一个依次转换，当转换到不合法的字符时，就停止转换，保留已经转换成功的数字
- `parseFloat()`:将数据转换成小数，他会对数据从左到右一个一个依次转换，当转换到不合法的字符时，就停止转换，保留已经成功的数字

#### 3.转为布尔值

只有1个方法

- Boolean()

  ```js
  	let n=0;
  	let q=Boolean(n)
  	console.log(q,'q');
  ```

  所有数据类型中，除了以下6种，其他数据转换后都为true

  - 0
  - NaN
  - ''（空字符串）
  - undefined
  - null
  - false

### 三，自动转换

#### 1.转换字符串

在JS种，`+`既可以做求和，也可以做字符串的拼接，规则就是相加的数据中，只要有一条是字符串，其他数据就会隐式转为字符串，进行拼接

```js
let a =22;
let b=''
let c =a+b;
let d= a+''
console.log(a);
console.log(c);
console.log(d);
```

#### 2.转换为数字

在JS种，除了`+`以外，其他数学运算都需要数字参与，如果参与运算的数据不是数字类型，JS会将数据隐式转为数字类型

```js
let e = '33';
let f = e - 0
console.log(e, 'e');
console.log(f);
```

#### 3.转为布尔值

在JS种提供了`!`来对布尔类型的数据进行反向操作，如果取反的数据不是布尔类型，JS会隐式将数据转换为布尔值，然后进行取反

```js
let g ='你好'
let m=!!g; //取反得到false，再次取反得到true
console.log(m,'m');
```

### 四，查看数据类型

JS提供了typeof的方法来查看数据类型

```js
let g ='你好'
let m=!!g;
console.log(m,'m');

// 查看数据类型

console.log('g',typeof g);
console.log('m',typeof m);
```

`typeof null`:得到的是`object`,浏览器在检测时会将二进制前三位为0的解析为object类型，null的二进制全为0.
