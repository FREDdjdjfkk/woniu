## 浮动

- 浮动常用于页面布局，可以实现让元素同行显示

- 语法

  ```css
  	float: left|right|none;
  ```

- 特点：

  1. 设置浮动的元素会同行显示，排列不下时会自动换行，不存在兼容问题
  2. 浮动的元素会脱离文档流，显示在标准文档流之上
  3. 原来的空间不再占用
  4. **行内元素**设置浮动之后，可以设置高度和宽度

- 注意：

  - 只有设置了浮动的元素才会同行显示
  - 当多个标签同时设置浮动时，后面浮动的元素会找到前面浮动的元素的边界就停下来，或者第一个浮动的元素会找到父元素的边界就停下来
  - **块级标签**没有设置宽度时，一旦设置了浮动，块级标签的宽度由内容决定

### 一，浮动布局带来的影响

标准文档流：在页面布局过程中，元素按照从上到下，从左到右，块级元素独占一行，行级元素共享一行的排列规范进行排列

脱离文档流：在页面布局过程中，元素不再遵循标准文档流的规范，而是按照自己的排列规范来

#### 1.子元素设置浮动之后，父元素高度塌陷

原因：子元素设置浮动之后，子元素会脱离文档流，原来标准文档流的空间不再占用，子元素就不会参与父元素高度的计算。

- 解决方案
  - 给父元素设置高度，不让父元素高度自适应
  - 给父元素设置`overflow:hidden`:将父标签变成一个BFC容器，容器里面的浮动元素会参与父元素高度的计算

### 二，清除浮动

- 清除浮动带来的影响

- 语法

  ```css
  clear:left|right|both
  ```

  - left:清除左浮动的影响
  - right：清除右浮动的影响
  - both：同时清除左浮动和右浮动

- 清除浮动的方法

  - 在浮动的元素后面添加一个空白的块级标签，设置clear属性来清除浮动

  - 给父元素添加一个伪元素选择器`::after`,来清除浮动（推荐）

    ```css
    .clearfix::after{
    			content: '';
    			display: block; 
    			clear: both;
    		}
    ```
