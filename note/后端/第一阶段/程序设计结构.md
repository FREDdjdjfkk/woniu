# 程序设计结构

例如：完成一个用户管理系统

## 分层分包

围绕用户完成一系列的操作



## 实体类

entity 实体包   （以后还会对实体做划分）  

实体类要求：属性私有化,对外提供getter and setter方法，可以添加构造方法，可以添加toString方法

```java
package entity;

public class User {

    private String userName;

    private String userPwd;

    private int userAge;

    private String userPhone;

    private String email;

    public User() {
    }

    public User(String userName, String userPwd, int userAge, String userPhone, String email) {
        this.userName = userName;
        this.userPwd = userPwd;
        this.userAge = userAge;
        this.userPhone = userPhone;
        this.email = email;
    }

    public String getUserName() {
        return userName;
    }

    public void setUserName(String userName) {
        this.userName = userName;
    }

    public String getUserPwd() {
        return userPwd;
    }

    public void setUserPwd(String userPwd) {
        this.userPwd = userPwd;
    }

    public int getUserAge() {
        return userAge;
    }

    public void setUserAge(int userAge) {
        this.userAge = userAge;
    }

    public String getUserPhone() {
        return userPhone;
    }

    public void setUserPhone(String userPhone) {
        this.userPhone = userPhone;
    }

    public String getEmail() {
        return email;
    }

    public void setEmail(String email) {
        this.email = email;
    }

    @Override
    public String toString() {
        return "User{" +
                "userName='" + userName + '\'' +
                ", userPwd='" + userPwd + '\'' +
                ", userAge=" + userAge +
                ", userPhone='" + userPhone + '\'' +
                ", email='" + email + '\'' +
                '}';
    }
}
```

## 用户管理系统业务接口

service包

功能设计:

添加用户，修改用户，删除用户，查询用户列表，登录系统

面向接口编程

用户类的业务接口

```java
package service;

import entity.User;

/**
 * 定义用户类有哪些功能
 */
public interface UserService {

    /**
     *登录方法
     * @param userName  用户名
     * @param userPwd  密码
     * @return  登录成功与否
     */
     boolean login(User[] users,String userName,String userPwd);

    /**
     * 添加用户
     */

    void addUser(User user);


    /**
     * 删除用户
     */

    void deleteUser(int userId);

    /**
     * 查看用户
     * @return
     */
    User[] selectUsers();


}

```

## 表示层

面向用户的，可以是控制台，图形用户界面，网页等....

```java
package view;

import entity.User;
import service.UserService;
import service.impl.UserServiceImpl;

import java.util.Scanner;

public class UserView {

    public static void main(String[] args) {
        //操作控制台
        UserView view = new UserView();
        User[] users = view.initUser();

        Scanner in = new Scanner(System.in);

        System.out.println("欢迎来到用户管理系统");
        System.out.println("请登录:");
        System.out.println("输入用户名:");
        String userName = in.nextLine();

        System.out.println("输入密码:");
        String userPwd = in.nextLine();

        //登录
        UserService userService = new UserServiceImpl();
        boolean loginResult = userService.login(users,userName,userPwd);

        if(loginResult){
            System.out.println("登录成功");
        }else {
            System.out.println("登录失败");
        }

    }

    public User[] initUser(){
        User user1 = new User(1,"admin","12345",20,"189xxx","xxx@qq.com");

        User user2 = new User(2,"test","12345",20,"189xxx","xxx@qq.com");

        User[] users = {user1,user2};

        return users;
    }
}

```
