## 一，css基础

所有标签默认是没有样式的

### 1.css的基本概念

CSS（Sascading Style Sheets）层叠样式表，主要用来控制页面中标签的样式，css样式是设置在标签上的

- 层叠：指的是css样式代码可以设置在多个地方，浏览器在渲染时会将多个地方的样式叠加在一起，形成最终的样式，相同的属性根据优先级层叠，不同的属性直接作用到标签上
- 样式表：指的是css样式代码

 

### 2.样式的来源

#### （1)浏览器默认样式

浏览器会默认给不同的标签添加不同的样式，比如p标签，h标签，a标签等

#### （2）浏览器用户自定义的样式

浏览器默认了用户可以更改部分样式的功能，比如字体大小，字体类型等

#### （3）用户自己编写的样式

- 内联样式
- 内部样式
- 外部样式



##### 内联样式

- 在标签上添加style属性，在style中写css代码

- 语法

  ```css
  <p style="css属性名1: css属性值1;css属性名2: css属性值2;">p标签</p>
  ```

- 注意：

  - 每个标签上都有自己的style属性，只能控制自己的样式
  - 同一个标签上只能设置一个style属性

- 缺点

  - 多个标签设置相同的样式时，需要手动给每个标签添加style属性，再书写css代码
  - html和css代码混在一起，不便于维护

##### 内部样式

- 在head标签中添加`style`标签，在style标签里面通过选择器来书写代码

- 语法

  ```css
  <head>
  	<style>
  		选择器 {
  			css属性名1: css属性值1；
                css属性名2: css属性值2;
  		}
  	</style>
  </head>
  ```

- 注意

  - 可以实现同时设置多个标签的样式
  - 但是html代码和css代码没有完全分开，在同一个HTML文件中

##### 外部样式

- 先创建一个后缀名为`.css`的文件，在文件中通过选择器来书写代码，再在head标签中通过`link`b标签引入css文件

- 语法

  ```
  <head>
  	<link rel="stylesheet" href="./css/06-外部css.css">
  </head>
  ```

- 注意

  - 将html和css完全分离开，便于后期维护
  - 以后可以将css文件进行压缩，减少文件的体积，优化网页
