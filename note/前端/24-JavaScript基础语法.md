## JavaScript的基础语法

### 一，注释

#### 1.单行注释

快捷键`ctrl+/`

```js
 <script>
		// 单行注释
		console.log(11);
	 </script>
```

#### 2.多行注释

```js
/*
		一行
		二行
		
		*/
```

### 二，输入与输出

#### 1.输入

输入，指的是页面中给用户一个可以输入内容的输入框，除了html的input标签以外，JS还提供了`prompt()`来实现输入功能

```js
<script>
		// 输入
		prompt('请输入你的名字')
	</script>
```

#### 2.输出

输出，指开发人员通过代码将一个文字内容通过浏览器输出给用户看

JS提供了三种输出方式

- `console.log();`:将内容显示在**开发工具**中
- `document.write('你好')`:将输出的内容显示**浏览器的页面**中
- `alert()`:将输出的内容显示在**浏览器弹窗**中

```html
<body>
    <script>
    
    </script>
 </body>
```
