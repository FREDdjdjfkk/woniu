## 列表标签

### 1.无序列表 ul

- 语法

  ```html
  <ul type="square">
  		<!--disc:默认值，实心圆  circle:空心圆 square正方向 -->
  		<li>html</li>
  		<li>css</li>
  		<li>js</li>
  	</ul>
  ```

  

### 2.有序列表 ol

- 语法

  ```html
  <ol type="1">
  		<!-- type指定列表的符号，默认值是1数字， -->
  		<li>html</li>
  		<li>css</li>
  		<li>js</li>
  	</ol>
  ```

  

### 3.定义列表

- 语法

  ```html
  <dl>
  		<dt>计算机学苑</dt>
  		<dd>物联网</dd>
  		<dd>java</dd>
  	</dl>
  ```
