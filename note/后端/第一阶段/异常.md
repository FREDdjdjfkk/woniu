# 异常

```properties
‌Java异常‌是指在程序运行过程中发生的错误或不正常情况，这些情况会干扰程序的正常执行流程，可能导致程序错误或崩溃
```

见过哪些异常，发生异常后程序被强制终止

```properties
数组下标越界 ArrayIndexOutOfException
InputMismatchException 输入的数据类型不匹配
NullPointerException 空指针异常
StackOverflowError  内存溢出
```

异常的出现说明程序员没有控制好一些数据和逻辑

### 方式一trycatch

```properties
try catch
```

```java
 String str = "2025-10-01";
        SimpleDateFormat simpleDateFormat = new SimpleDateFormat("yyyy-MM-dd");

        try{
            //把可能要发生异常的代码放入try块中
            Date date = simpleDateFormat.parse(str);//产生一个ParseException e = new ParseException();


            //上面如果发生异常，下面的代码不执行
            System.out.println("xxx");

        }catch (ParseException e){
            System.out.println(e.getMessage());//获取详细的异常信息
            System.out.println("发生异常");
        }

        System.out.println("正常执行");

```

一个catch块处理多个不同的异常类型:

```properties
catch中的异常类型不要出现继承关系,否则编译不通过
```

```java
 String str = "2025-10-01";
        SimpleDateFormat simpleDateFormat = new SimpleDateFormat("yyyy-MM-dd");

        try{
            //把可能要发生异常的代码放入try块中
            Date date = simpleDateFormat.parse(str);//产生一个ParseException e = new ParseException();


            String str1 = null;
            str1.charAt(0);  //这里会发生一个空指针异常   NullPointerException e = new NullPointerException();

            //上面如果发生异常，下面的代码不执行
            System.out.println("xxx");

        }catch (ParseException | NullPointerException e){
            System.out.println(e.getMessage());//获取详细的异常信息
            System.out.println("发生异常");
        }

        System.out.println("正常执行");

```

使用多个 catch块处理不同的异常类型

```properties
catch中的异常类型编写顺序，父类异常类型要写到子类异常类型的后面
```

finally

## 自定义异常

```properties
在开发过程中，可能我们需要去定义一些业务异常
```

```java
public class MyException extends RuntimeException{

    public MyException(){

    }
    public MyException(String msg){
        super(msg);
    }

}

```

```java
public class TestMyException {

    public static void main(String[] args) {

        //输入一个手机号码
        String phone = "xxxx";


            checkPhone(phone);



    }

    public static void checkPhone(String phone){

        String regex ="^1[3-9][0-9]{9}";
        if(!phone.matches(regex)){
            throw  new MyException("手机号码格式不正确");
        }

    }
}

```
