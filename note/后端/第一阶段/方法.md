# 方法

```properties
完成某件事情所想出的办法

将一段代码进行封装的过程

当我们需要在多个地方执行一段相同的代码时,可以将这段代码进行封装在方法中
```



## 方法的定义

```properties
语法:
访问修饰符(public) 其他修饰符(static) 返回值类型(无返回值void) 方法名(数据类型 参数名  --可有可无,多个参数逗号隔开){
	方法体;
} 
```

- 访问修饰符:public protected 默认的  private
- 其他修饰符  static   final  abstract
- 返回值类型：任意数据类型  无返回值用 void 
- 方法名：自定义（标识符：一般首字母小写）
- 参数列表: 0 个或多个参数，多个参数逗号隔开

### 无参无返回值的方法

```java
    public  static void printHelloWorld(){
        System.out.println("hello world");
    }

```

### 有参数无返回值

```java
    //输出a和b的和
    public  static  void printSum(int a,int b){
        
        System.out.println("和为:"+(a+b));
    }
```

### 有参数有返回值

```java
 public static int getSum(int a,int b){
        return a+b;
    }
```

```properties
有没有参数，取决于做这件事情需不需要某个前提条件(把需要的数据作为参数)

有没有返回值，取决于做这件事需不要得到一个结果，并做下一步操作
```

## 方法的调用

```properties
方法名(参数);
```

形参：是一个变量，用来接收方法调用时传过来的实参的值

实参：方法调用时传过来的实际值
