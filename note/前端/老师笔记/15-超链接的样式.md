## 超链接样式

- 语法

  ```css
  /* 像未访问过的超链接添加样式 */
  		a:link {
  			color: green;
  		}
  
  		/* 向访问过的超链接添加样式 */
  		a:visited {
  			color: orange;
  		}
  
  		/* 鼠标移入时的样式  hover需要放在link和visited之后*/
  		a:hover {
  			color: red;
  		}
  
  		/* 当鼠标按下时添加样式 */
  		a:active {
  			color: plum;
  		}
  ```

- 注意：

  - `link`和`visited`是a标签独有的
  - 给超链接添加样式时，`:hover`必须放在`:link`和`:visited`之后，`:active`必须放在`:hover`之后
