# 反射

## java的反射机制

创建对象  User user = new User();

调用方法:   user.xxx();

调用属性: user.xxx;

```properties
程序在运行过程中，动态创建对象，动态调用属性和方法的过程就是java的反射机制
```

## 字节码对象Class

```properties
类模版对象

当一个加载时就会将这个类的模版放入方法区的class区中
```

比如这个类实现了哪些接口，这个类有哪些属性，有哪些构造方法，有哪些方法 注解....

每个类都有一个类模版对象,有且只有一个

## 获取Class对象的方式有三种

- 使用Class.forName("包名+类名")
- 使用类名.class
- 使用对象.getClass()

```java
  //获取Class方式一 会加载指定的类并执行static块
        Class<?> userClass = Class.forName("com.woniu.dao.User");

            //方式二  不会执行static块
        Class<?> userClass2 =  User.class;

           //方式三  通过对象获取 执行静态块
          User  user1 = new User();
        User  user2 = new User();
        Class<?> userClass3 =  user1.getClass();

        Class<?> userClass4 =  user2.getClass();

        System.out.println(userClass == userClass4);
```
