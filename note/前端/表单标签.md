# 表单标签

## 介绍

HTML 表单用于收集用户的输入信息。

HTML 表单表示文档中的一个区域，此区域包含交互控件，将用户收集到的信息发送到 Web 服务器。

HTML 表单通常包含各种输入字段、复选框、单选按钮、下拉列表等元素。

## **组成**

- `<form>` 元素用于创建表单，`action` 属性定义了表单数据提交的目标 URL，`method` 属性定义了提交数据的 HTTP 方法（这里使用的是 "post"）。
- `<label>` 元素用于为表单元素添加标签，提高可访问性。
- `<input>` 元素是最常用的表单元素之一，它可以创建文本输入框、密码框、单选按钮、复选框等。`type` 属性定义了输入框的类型，`id` 属性用于关联 `<label>` 元素，`name` 属性用于标识表单字段。
- `<select>` 元素用于创建下拉列表，而 `<option>` 元素用于定义下拉列表中的选项



## **格式**：

```html
<form action="/" method="post">
    <!-- 文本输入框 -->
    <label for="name">用户名:</label>
    <input type="text" id="name" name="name" required>

    <br>

    <!-- 密码输入框 -->
    <label for="password">密码:</label>
    <input type="password" id="password" name="password" required>

    <br>

    <!-- 单选按钮 -->
    <label>性别:</label>
    <input type="radio" id="male" name="gender" value="male" checked>
    <label for="male">男</label>
    <input type="radio" id="female" name="gender" value="female">
    <label for="female">女</label>

    <br>

    <!-- 复选框 -->
    <input type="checkbox" id="subscribe" name="subscribe" checked>
    <label for="subscribe">订阅推送信息</label>

    <br>

    <!-- 下拉列表 -->
    <label for="country">国家:</label>
    <select id="country" name="country">
        <option value="cn">CN</option>
        <option value="usa">USA</option>
        <option value="uk">UK</option>
    </select>

    <br>

    <!-- 提交按钮 -->
    <input type="submit" value="提交">
</form>
```

## **实践代码**

```html
<html>
<body>
    <!-- method默认get类型 -->
    <form action="./01html.html" method="">
        <!-- for用于聚焦id，点击文本聚焦该id的输入框 ,input的value设置输入框的默认值 ,name是提交数据的类型-->
        <label for="user">账号</label>
        <input type="text" id="user" value="admin" name="username">
        <br>
        <label for="">密码</label>
        <input type="password" required>
        <br>
        <label for="">只读输入框</label>
        <input type="text" name="" id="" readonly value="readonly">
        <br>
        <label for="">禁用</label>
        <input type="text" name="" id="" disabled>
        <br>
        <!-- 数字输入框，只允许输入数字 -->
        <label for="">数字</label>
        <input type="number">
        <br>
        <!-- 邮箱输入框，提供简单的邮箱格式认证 -->
        <label for="">邮箱</label>
        <input type="email">
        <br>
        <!-- 文件上传，默认上传一个 -->
        <label for="">上传文件</label>
        <input type="file" multiple>
        <br>
        <!-- 时间控件 -->
        <label for="">日期</label>
        <input type="date">
        <br>
        <label for="">年月</label>
        <input type="month">
        <br>
        <label for="">周数</label>
        <input type="image">
        <br>
        <!-- 单选列表 -->
        <label for="">男</label>
        <!-- checked默认选中 -->
        <input type="radio" name="gender" checked>
        <label for="">女</label>
        <input type="radio" name="gender">
        <br>
        <!-- 下拉列表 -->
        <label for="">数字</label>
            <select name="number" >
                <option value="">1</option>
                <option value="">2</option>
                <option value="">3</option>
            </select>
        <br>
        <!-- 文本域 -->
        <textarea name="" id="" rows="10" cols="50"></textarea>
        <br>
        <input type="submit">
    </form>

</body>

</html>
```
